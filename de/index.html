Ein Protokoll für Secrets und KI-Agenten · macOS

Dein Agent kennt den Namen.
Nie den Wert.

SecretBar ist ein Befehl und eine Menüleisten-App für den Mac. Passwörter, Tokens und API-Schlüssel bleiben in der Secure Enclave. Der Agent fragt nach dem Namen, ein Mensch bestätigt, der Prozess erhält den Wert, und die Ausgabe kommt geschwärzt zurück.

$ brew install secretbar/tap/secretbar

Das Protokoll

Sechs Regeln, denen der Wert folgt.

Jede Funktion von SecretBar setzt eine davon durch. Keine hängt davon ab, dass sich der Agent gut benimmt.

  1. §1

    Eingabe

    Ein Mensch tippt den Wert in einen verdeckten macOS-Dialog: secret ask NAME. Der Chat sieht ihn nie. secret gen erzeugt einen Zufallswert, den niemand sieht.

  2. §2

    Speicherung

    Schlüssel in der Secure Enclave versiegeln jeden Wert: P-256 und Post-Quanten-ML-KEM-768. Die ganze Datei ist zusätzlich verschlüsselt. Nichts geht in eine Cloud.

  3. §3

    Zugriff

    Jedes Lesen braucht Touch ID oder Apple Watch. Die Kulanzzeit gleitet 30 Minuten lang und endet, wenn der Bildschirm gesperrt wird. Eine Freigabe gibt einem Agenten benannte Secrets für bis zu 24 Stunden, nach einmal Touch ID.

  4. §4

    Verwendung

    secret run legt den Wert in die Umgebung eines einzigen Prozesses. Nicht in argv, eine Datei oder den Chat. Eine .env-Datei enthält Verweise: secret:NAME.

  5. §5

    Ausgabe

    Jeder Wert in stdout und stderr kommt als *** zurück, auch in base64- und URL-Kodierung. Ein Claude Code Hook stoppt cat .env, secret get und env, bevor sie laufen.

  6. §6

    Nachweis

    Ein Zugriffsprotokoll hält fest, wer welchen Namen wann gelesen hat: agent oder human. Nur Namen.

Außerdem dabei

  • Suche nach Bedeutung. secret ls --ask "shop database" findet Namen mit dem lokalen Modell von macOS 27. Es liest Namen und Kommentare, nie Werte.
  • Browser-Sitzungen. Eine Safari-Sitzung zieht als Cookie-Jar in den Speicher um. curl nutzt sie, der Agent sieht nie ein Cookie.
  • GitHub Actions. secret gh NAME -R owner/repo übergibt einen Wert über stdin an gh secret set, nach deiner Bestätigung.
  • Ablauf und Backup. Tokens mit Datum erinnern dich, bevor sie ablaufen. secret export schreibt eine AES-256-Datei für einen neuen Mac.
  • Jeder Agent. Claude Code, Codex, Cursor, Aider: jeder Agent, der Shell-Befehle ausführt. Claude Code bekommt zusätzlich den Hook und fertige Regeln.

Die Menüleisten-App

Die menschliche Seite des Protokolls.

⌥⌘S aus jeder App, Spotlight, Siri und Kurzbefehle. Eine Karte für jedes Secret mit den .env-Dateien, die es nutzen. Die App liest nie einen Wert: Der Helfer legt ihn in die Zwischenablage und löscht ihn nach 30 Sekunden.

  • Schnellsuche: ↩ kopiert den Verweis, ⇧↩ den Wert
  • + in der Menüleiste: ein neues Secret, sein Verweis in der Zwischenablage
  • Aktivität: Agent-Läufe und Touch ID-Anfragen

Fragen

Sieht der KI-Agent jemals den Wert eines Secrets?
Nein. Der Agent arbeitet mit Namen. Der Wert geht in die Umgebung des Befehls, der ihn braucht, und die Ausgabe kommt mit *** statt des Werts zurück. Ein Claude Code Hook stoppt Befehle, die einen Wert ausgeben würden.
Wo werden die Secrets gespeichert?
In einer verschlüsselten Datei auf deinem Mac. Schlüssel in der Secure Enclave versiegeln jeden Wert. Lesen braucht Touch ID, Apple Watch oder das Mac-Passwort. Nichts geht in eine Cloud.
Mit welchen KI-Agenten funktioniert es?
Mit jedem Agenten, der Shell-Befehle ausführt: Claude Code, Codex, Cursor, Aider und anderen. Claude Code bekommt zusätzlich einen Hook und fertige Regeln für seine CLAUDE.md.
Was kostet es?
Nichts. SecretBar ist Open Source unter der MIT-Lizenz.
Welche macOS-Version brauche ich?
macOS 14 oder neuer auf einem Mac mit Secure Enclave (Apple Chip oder T2). Der Post-Quanten-Speicher braucht macOS 26. Die Suche nach Bedeutung braucht macOS 27 mit Apple Intelligence.
Kann ich meine Secrets auf einen neuen Mac umziehen?
Ja. secret export schreibt eine Datei, verschlüsselt mit AES-256 und deinem Backup-Passwort. secret restore liest sie auf dem neuen Mac.

Installation

Drei Zeilen. Dann hier unterschreiben.

  1. Der Befehl, beide Helfer und die zsh-Vervollständigung
    $ brew install secretbar/tap/secretbar
  2. Der Speicher, dann das erste Secret, in einem Dialog eingetippt
    $ secret init && secret ask MY_TOKEN
  3. Der Claude Code Hook, die Agent-Regeln und die Menüleisten-App
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 oder neuer. Keine Abhängigkeiten außer den Systemwerkzeugen. Kostenlos und Open Source, MIT.
