Funktionen

    
Gemacht für die Arbeit mit einem Agenten.

  

  

    

      
⌘

      
Verdeckte Eingabe

      
secret ask NAME öffnet einen macOS-Dialog. Sie tippen den Wert. Der Agent erhält stored: NAME. secret gen erzeugt einen Zufallswert, den niemand sieht.

      
$ secret gen -l 32 -c "shop: db password" SHOP_DB_PASSWORD
stored: SHOP_DB_PASSWORD

    

    

      
***

      
Maskierte Ausgabe

      
run --mask ersetzt jeden Wert in stdout und stderr durch ***, auch in base64- und URL-Kodierung. Unter Claude Code immer aktiv.

    

    

      

      
Claude Code Hook

      
Stoppt secret get, cat .env, security … -w und env in run, bevor sie starten.

      
cat .envVon SecretBar blockiert

    

    

      
PQ

      
Post-Quanten-Speicher

      
Ab macOS 26 versiegeln zwei Secure-Enclave-Schlüssel jeden Wert: P-256 und ML-KEM-768. Eine heute kopierte Datei bleibt auch für einen künftigen Quantencomputer verschlossen. secret touchid pq konvertiert einen alten Speicher nach einmal Touch ID.

    

    

      
⏲

      
Freigabe für einen Agenten

      
secret lease --for 8h NAME… hält die genannten Secrets bis zu 24 Stunden bereit, nach einmal Touch ID, das sie benennt. Sie bleiben bei gesperrtem Bildschirm lesbar. Jeder andere Name scheitert sofort mit not leased. secret lease --revoke beendet die Freigabe.

    

    

      
?

      
Suche nach Bedeutung

      
secret ls --ask "shop database password" findet Namen mit dem lokalen Apple-Modell von macOS 27. Das Modell sieht nur Namen und Kommentare, nie einen Wert, und nichts verlässt den Mac.

    

    

      
⇪

      
GitHub Actions

      
secret gh NAME -R owner/repo übergibt einen Wert über stdin an gh secret set, nachdem Sie bestätigt haben.

    

    

      
🍪

      
Browsersitzungen

      
secret cookie pull DOMAIN --all --as NAME übernimmt eine Safari-Sitzung als Cookie-Jar in den Speicher. Eine Safari-Erweiterung erfasst reine Sitzungscookies. secret run --cookie-jar NAME gibt curl ein temporäres Jar, das nach dem Befehl gelöscht wird.

Sicherheit

    
Was es verhindert.
Und was nicht.

  

  

    
Ein Wert im Chat
Eingabe im Dialog, Generierung, maskierte Ausgabe, der Hook.
Ein Wert in einer eigenen Kodierung, zum Beispiel base64(user:pass).

    
Ein Wert in ps
Werte laufen über stdin und Dateideskriptoren.
set NAME VALUE mit dem Wert als Argument.

    
Ein Prozess liest hinter Ihrem Rücken
Der Secure-Enclave-Schlüssel funktioniert nur nach Touch ID oder Apple Watch, für jeden Prozess mit jeder Signatur.
Innerhalb der Kulanzzeit. Sie gleitet: 30 Minuten Leerlauf, höchstens 8 Stunden. Sperre oder Ruhezustand beendet sie.

    
Verlust des Mac
secret export: AES-256, PBKDF2 mit 600 000 Iterationen.
Ein vergessenes Backup-Passwort kann niemand wiederherstellen.

  






  

    
FAQ

    
Fragen.

  

  

    
Sieht der KI-Agent jemals den Wert eines Secrets?
Nein. Der Agent arbeitet mit Namen. Der Wert geht in die Umgebung des Befehls, der ihn braucht, und die Ausgabe kommt mit *** statt des Werts zurück. Ein Claude Code Hook stoppt Befehle, die einen Wert ausgeben würden.

    
Wo werden die Secrets gespeichert?
In einer verschlüsselten Datei auf Ihrem Mac. Schlüssel in der Secure Enclave versiegeln jeden Wert. Zum Lesen braucht es Touch ID, Apple Watch oder das Mac-Passwort. Nichts geht in eine Cloud.

    
Mit welchen KI-Agenten funktioniert es?
Mit jedem Agenten, der Shell-Befehle ausführt: Claude Code, Codex, Cursor, Aider und andere. Claude Code erhält zusätzlich einen Hook und fertige Regeln für seine CLAUDE.md.

    
Was kostet es?
Nichts. SecretBar ist Open Source unter der MIT-Lizenz.

    
Welche macOS-Version brauche ich?
macOS 14 oder neuer auf einem Mac mit Secure Enclave (Apple Chip oder T2). Der Post-Quanten-Speicher braucht macOS 26. Die Suche nach Bedeutung braucht macOS 27 mit Apple Intelligence.

    
Kann ich meine Secrets auf einen neuen Mac übertragen?
Ja. secret export schreibt eine Datei, verschlüsselt mit AES-256 und Ihrem Backup-Passwort. secret restore liest sie auf dem neuen Mac.
