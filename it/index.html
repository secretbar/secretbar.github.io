Funzioni

    
Fatto per lavorare con un agente.

  

  

    

      
⌘

      
Inserimento nascosto

      
secret ask NAME apre una finestra di macOS. Tu digiti il valore. L’agente riceve stored: NAME. secret gen crea un valore casuale che nessuno vede.

      
$ secret gen -l 32 -c "shop: db password" SHOP_DB_PASSWORD
stored: SHOP_DB_PASSWORD

    

    

      
***

      
Output mascherato

      
run --mask sostituisce ogni valore con *** in stdout e stderr, anche in base64 e codifica URL. Sempre attivo con Claude Code.

    

    

      

      
Hook per Claude Code

      
Ferma secret get, cat .env, security … -w e env dentro run prima che partano.

      
cat .envBloccato da SecretBar

    

    

      
PQ

      
Archivio post-quantistico

      
Da macOS 26, due chiavi della Secure Enclave sigillano ogni valore: P-256 e ML-KEM-768. Un file copiato oggi resta chiuso anche per un futuro computer quantistico. secret touchid pq converte un vecchio archivio dopo un solo Touch ID.

    

    

      
⏲

      
Concessione a un agente

      
secret lease --for 8h NAME… tiene disponibili i segreti indicati fino a 24 ore dopo un Touch ID che li nomina. Restano leggibili a schermo bloccato. Ogni altro nome fallisce subito con not leased. secret lease --revoke la termina.

    

    

      
?

      
Ricerca per significato

      
secret ls --ask "shop database password" trova i nomi con il modello Apple sul dispositivo di macOS 27. Il modello vede solo nomi e commenti, mai un valore, e nulla lascia il Mac.

    

    

      
⇪

      
GitHub Actions

      
secret gh NAME -R owner/repo invia un valore a gh secret set tramite stdin, dopo la tua conferma.

    

    

      
🍪

      
Sessioni del browser

      
secret cookie pull DOMAIN --all --as NAME sposta una sessione di Safari nell’archivio come cookie jar. Un’estensione di Safari cattura i cookie di sessione. secret run --cookie-jar NAME dà a curl un jar temporaneo eliminato dopo il comando.

    

    

      
.env

      
Riferimenti, non valori

      
TOKEN=secret:MY_TOKEN nel tuo .env. secret import sposta un file esistente. secret check mostra cosa manca.

Sicurezza

    
Cosa blocca.
E cosa no.

  

  

    
Un valore nella chat
Inserimento nella finestra, generazione, output mascherato, l’hook.
Un valore in una codifica personalizzata, per esempio base64(user:pass).

    
Un valore in ps
I valori passano per stdin e descrittori di file.
set NAME VALUE con il valore come argomento.

    
Un processo legge alle tue spalle
La chiave della Secure Enclave funziona solo dopo Touch ID o Apple Watch, per ogni processo con qualsiasi firma.
Nel periodo di tolleranza. Scorre: 30 minuti di inattività, 8 ore al massimo. Blocco schermo o stop lo terminano.

    
Perdita del Mac
secret export: AES-256, PBKDF2 con 600 000 iterazioni.
Nessuno può recuperare una password di backup dimenticata.

  






  

    
FAQ

    
Domande.

  

  

    
L’agente IA vede mai il valore di un segreto?
No. L’agente lavora con i nomi. Il valore va nell’ambiente del comando che ne ha bisogno e l’output torna con *** al posto del valore. Un hook per Claude Code ferma i comandi che stamperebbero un valore.

    
Dove sono conservati i segreti?
In un unico file cifrato sul tuo Mac. Le chiavi nella Secure Enclave sigillano ogni valore. Per leggere servono Touch ID, Apple Watch o la password del Mac. Niente va nel cloud.

    
Con quali agenti IA funziona?
Con qualsiasi agente che esegue comandi shell: Claude Code, Codex, Cursor, Aider e altri. Claude Code riceve anche un hook e regole pronte per il suo CLAUDE.md.

    
Quanto costa?
Niente. SecretBar è open source con licenza MIT.

    
Quale versione di macOS serve?
macOS 14 o successivo su un Mac con Secure Enclave (chip Apple o T2). L’archivio post-quantistico richiede macOS 26. La ricerca per significato richiede macOS 27 con Apple Intelligence.

    
Posso spostare i miei segreti su un nuovo Mac?
Sì. secret export scrive un file cifrato con AES-256 e la tua password di backup. secret restore lo legge sul nuovo Mac.
