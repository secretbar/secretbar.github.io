Un protocollo per segreti e agenti IA · macOS

Il tuo agente conosce il nome.
Mai il valore.

SecretBar è un comando e un’app per la barra dei menu del Mac. Password, token e chiavi API restano nella Secure Enclave. L’agente chiede per nome, una persona conferma, il processo riceve il valore e l’output torna oscurato.

$ brew install secretbar/tap/secretbar

Il protocollo

Il valore segue sei regole.

Ogni funzione di SecretBar ne applica una. Nessuna dipende dal buon comportamento dell’agente.

  1. §1

    Inserimento

    Una persona digita il valore in una finestra nascosta di macOS: secret ask NAME. La chat non lo vede mai. secret gen crea un valore casuale che nessuno vede.

  2. §2

    Archiviazione

    Chiavi nella Secure Enclave sigillano ogni valore: P-256 e ML-KEM-768, post-quantistico. L’intero file è cifrato una seconda volta. Niente va nel cloud.

  3. §3

    Accesso

    Ogni lettura richiede Touch ID o Apple Watch. Il periodo di tolleranza scorre per 30 minuti e finisce quando lo schermo si blocca. Una concessione dà a un agente segreti indicati per nome fino a 24 ore, dopo un solo Touch ID.

  4. §4

    Uso

    secret run mette il valore nell’ambiente di un solo processo. Non in argv, in un file o nella chat. Un file .env contiene riferimenti: secret:NAME.

  5. §5

    Output

    Ogni valore in stdout e stderr torna come ***, anche in base64 e in codifica URL. Un hook per Claude Code ferma cat .env, secret get e env prima che partano.

  6. §6

    Registro

    Un registro accessi conserva chi ha letto quale nome e quando: agent o human. Solo nomi.

Nella confezione anche

  • Ricerca per significato. secret ls --ask "shop database" trova i nomi con il modello locale di macOS 27. Legge nomi e commenti, mai valori.
  • Sessioni del browser. Una sessione di Safari passa nell’archivio come cookie jar. curl la usa, l’agente non vede mai un cookie.
  • GitHub Actions. secret gh NAME -R owner/repo invia un valore a gh secret set su stdin, dopo la tua conferma.
  • Scadenze e backup. I token con una data ti avvisano prima di scadere. secret export scrive un unico file AES-256 per un nuovo Mac.
  • Modalità YOLO. Disattivata per impostazione predefinita. secret yolo on o l’interruttore nel menu chiede Touch ID una sola volta. Poi gli agenti leggono ogni segreto senza domande finché non la disattivi, anche con lo schermo bloccato. L’output resta mascherato e solo tu puoi attivarla.
  • Qualsiasi agente. Claude Code, Codex, Cursor, Aider: qualsiasi agente che esegue comandi shell. Claude Code riceve anche l’hook e regole pronte.

L’app per la barra dei menu

Il lato umano del protocollo.

⌥⌘S da qualsiasi app, Spotlight, Siri e Comandi rapidi. Una scheda per ogni segreto con i file .env che lo usano. L’app non legge mai un valore: l’helper lo mette negli appunti e li svuota dopo 30 secondi.

  • Ricerca rapida: ↩ copia il riferimento, ⇧↩ il valore
  • + nella barra dei menu: un nuovo segreto, con il riferimento negli appunti
  • Attività: esecuzioni dell’agente e richieste di Touch ID

Domande

L’agente IA vede mai il valore di un segreto?
No. L’agente lavora con i nomi. Il valore va nell’ambiente del comando che ne ha bisogno e l’output torna con *** al posto del valore. Un hook per Claude Code ferma i comandi che stamperebbero un valore.
Dove sono conservati i segreti?
In un unico file cifrato sul tuo Mac. Chiavi nella Secure Enclave sigillano ogni valore. Una lettura richiede Touch ID, Apple Watch o la password del Mac. Niente va nel cloud.
Con quali agenti IA funziona?
Con qualsiasi agente che esegue comandi shell: Claude Code, Codex, Cursor, Aider e altri. Claude Code riceve anche un hook e regole pronte per il suo CLAUDE.md.
Quanto costa?
Niente. SecretBar è open source con licenza MIT.
Quale versione di macOS serve?
macOS 14 o successivo su un Mac con Secure Enclave (chip Apple o T2). L’archivio post-quantistico richiede macOS 26. La ricerca per significato richiede macOS 27 con Apple Intelligence.
Posso spostare i miei segreti su un nuovo Mac?
Sì. secret export scrive un file cifrato con AES-256 e la tua password di backup. secret restore lo legge sul nuovo Mac.

Installazione

Tre righe, poi firma qui.

  1. Il comando, entrambi gli helper e il completamento zsh
    $ brew install secretbar/tap/secretbar
  2. L’archivio, poi il primo segreto, digitato in una finestra
    $ secret init && secret ask MY_TOKEN
  3. L’hook per Claude Code, le regole per l’agente e l’app per la barra dei menu
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 o successivo. Nessuna dipendenza oltre agli strumenti di sistema. Gratuito e open source, MIT.
