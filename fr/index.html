Fonctions

    
Conçu pour travailler avec un agent.

  

  

    

      
⌘

      
Saisie masquée

      
secret ask NAME ouvre un dialogue macOS. Vous saisissez la valeur. L’agent reçoit stored: NAME. secret gen crée une valeur aléatoire que personne ne voit.

      
$ secret gen -l 32 -c "shop: db password" SHOP_DB_PASSWORD
stored: SHOP_DB_PASSWORD

    

    

      
***

      
Sortie masquée

      
run --mask remplace chaque valeur par *** dans stdout et stderr, y compris en base64 et en encodage URL. Toujours actif sous Claude Code.

    

    

      

      
Hook Claude Code

      
Bloque secret get, cat .env, security … -w et env dans run avant leur lancement.

      
cat .envBloqué par SecretBar

    

    

      
PQ

      
Stockage post-quantique

      
Depuis macOS 26, deux clés de la Secure Enclave scellent chaque valeur : P-256 et ML-KEM-768. Un fichier copié aujourd’hui reste fermé à un futur ordinateur quantique. secret touchid pq convertit un ancien stockage après un seul Touch ID.

    

    

      
⏲

      
Bail pour un agent

      
secret lease --for 8h NAME… garde les secrets nommés jusqu’à 24 heures après un Touch ID qui les nomme. Ils restent lisibles écran verrouillé. Tout autre nom échoue aussitôt avec not leased. secret lease --revoke y met fin.

    

    

      
?

      
Recherche par le sens

      
secret ls --ask "shop database password" trouve des noms avec le modèle Apple sur l’appareil de macOS 27. Le modèle ne voit que noms et commentaires, jamais une valeur, et rien ne quitte le Mac.

    

    

      
⇪

      
GitHub Actions

      
secret gh NAME -R owner/repo transmet une valeur à gh secret set via stdin, après votre confirmation.

    

    

      
🍪

      
Sessions de navigateur

      
secret cookie pull DOMAIN --all --as NAME place une session Safari dans le stockage sous forme de cookie jar. Une extension Safari capture les cookies de session. secret run --cookie-jar NAME donne à curl un jar temporaire supprimé après la commande.

    

    

      
.env

      
Des références, pas des valeurs

      
TOKEN=secret:MY_TOKEN dans votre .env. secret import reprend un fichier existant. secret check montre ce qui manque.

Sécurité

    
Ce qu’il bloque.
Et ce qu’il ne bloque pas.

  

  

    
Une valeur dans le chat
Saisie par dialogue, génération, sortie masquée, le hook.
Une valeur dans un encodage maison, par exemple base64(user:pass).

    
Une valeur dans ps
Les valeurs passent par stdin et des descripteurs de fichier.
set NAME VALUE avec la valeur en argument.

    
Un processus lit dans votre dos
La clé de la Secure Enclave ne fonctionne qu’après Touch ID ou Apple Watch, pour tout processus et toute signature.
Pendant le délai de grâce. Il glisse : 30 minutes d’inactivité, 8 heures au plus. Verrouillage ou suspension y met fin.

    
Perte du Mac
secret export : AES-256, PBKDF2 à 600 000 itérations.
Personne ne peut récupérer un mot de passe de sauvegarde oublié.

  






  

    
FAQ

    
Questions.

  

  

    
L’agent IA voit-il un jour la valeur d’un secret ?
Non. L’agent travaille avec des noms. La valeur va dans l’environnement de la commande qui en a besoin, et la sortie revient avec *** à la place de la valeur. Un hook Claude Code bloque les commandes qui afficheraient une valeur.

    
Où sont stockés les secrets ?
Dans un seul fichier chiffré sur votre Mac. Des clés de la Secure Enclave scellent chaque valeur. Une lecture exige Touch ID, Apple Watch ou le mot de passe du Mac. Rien ne part dans un cloud.

    
Avec quels agents IA fonctionne-t-il ?
Avec tout agent qui exécute des commandes shell : Claude Code, Codex, Cursor, Aider et d’autres. Claude Code reçoit en plus un hook et des règles prêtes pour son CLAUDE.md.

    
Combien ça coûte ?
Rien. SecretBar est open source sous licence MIT.

    
Quelle version de macOS faut-il ?
macOS 14 ou ultérieur sur un Mac avec Secure Enclave (puce Apple ou T2). Le stockage post-quantique exige macOS 26. La recherche par le sens exige macOS 27 avec Apple Intelligence.

    
Puis-je transférer mes secrets vers un nouveau Mac ?
Oui. secret export écrit un fichier chiffré avec AES-256 et votre mot de passe de sauvegarde. secret restore le lit sur le nouveau Mac.
