Un protocole pour les secrets et les agents IA · macOS

Votre agent connaît le nom.
Jamais la valeur.

SecretBar est une commande et une app de barre des menus pour le Mac. Mots de passe, jetons et clés d’API restent dans la Secure Enclave. L’agent demande par le nom, un humain confirme, le processus reçoit la valeur, et la sortie revient caviardée.

$ brew install secretbar/tap/secretbar

Le protocole

La valeur obéit à six règles.

Chaque fonction de SecretBar en applique une. Aucune ne compte sur la bonne conduite de l’agent.

  1. §1

    Saisie

    Un humain tape la valeur dans une boîte de dialogue macOS masquée : secret ask NAME. Le chat ne la voit jamais. secret gen crée une valeur aléatoire que personne ne voit.

  2. §2

    Stockage

    Des clés de la Secure Enclave scellent chaque valeur : P-256 et ML-KEM-768, post-quantique. Le fichier entier est chiffré une seconde fois. Rien ne part dans un cloud.

  3. §3

    Accès

    Toute lecture exige Touch ID ou l’Apple Watch. Le délai de grâce glisse sur 30 minutes et prend fin au verrouillage de l’écran. Un bail donne à un agent des secrets nommés pour 24 heures au plus, après un seul Touch ID.

  4. §4

    Usage

    secret run place la valeur dans l’environnement d’un seul processus. Ni dans argv, ni dans un fichier, ni dans le chat. Un fichier .env contient des références : secret:NAME.

  5. §5

    Sortie

    Chaque valeur dans stdout et stderr revient sous la forme ***, aussi en base64 et en encodage URL. Un hook Claude Code bloque cat .env, secret get et env avant leur exécution.

  6. §6

    Traçabilité

    Un journal d’accès garde qui a lu quel nom, et quand : agent ou human. Les noms seulement.

Aussi dans la boîte

  • Recherche par le sens. secret ls --ask "shop database" trouve des noms avec le modèle local de macOS 27. Il lit les noms et les commentaires, jamais les valeurs.
  • Sessions du navigateur. Une session Safari entre dans le stockage sous forme de cookie jar. curl s’en sert, l’agent ne voit jamais un cookie.
  • GitHub Actions. secret gh NAME -R owner/repo envoie une valeur à gh secret set sur stdin, après votre confirmation.
  • Expiration et sauvegarde. Les jetons datés vous préviennent avant d’expirer. secret export écrit un seul fichier AES-256 pour un nouveau Mac.
  • Tout agent. Claude Code, Codex, Cursor, Aider : tout agent qui lance des commandes shell. Claude Code reçoit en plus le hook et des règles prêtes à l’emploi.

L’app de barre des menus

Le versant humain du protocole.

⌥⌘S depuis n’importe quelle app, Spotlight, Siri et Raccourcis. Une fiche par secret avec les fichiers .env qui l’utilisent. L’app ne lit jamais une valeur : l’assistant la place dans le presse-papiers et l’efface après 30 secondes.

  • Recherche rapide : ↩ copie la référence, ⇧↩ la valeur
  • + dans la barre des menus : un nouveau secret, sa référence dans le presse-papiers
  • Activité : exécutions de l’agent et demandes Touch ID

Questions

L’agent IA voit-il un jour la valeur d’un secret ?
Non. L’agent travaille avec des noms. La valeur va dans l’environnement de la commande qui en a besoin, et la sortie revient avec *** à la place de la valeur. Un hook Claude Code bloque les commandes qui afficheraient une valeur.
Où les secrets sont-ils stockés ?
Dans un seul fichier chiffré sur votre Mac. Des clés de la Secure Enclave scellent chaque valeur. Une lecture exige Touch ID, l’Apple Watch ou le mot de passe du Mac. Rien ne part dans un cloud.
Avec quels agents IA fonctionne-t-il ?
Avec tout agent qui lance des commandes shell : Claude Code, Codex, Cursor, Aider et d’autres. Claude Code reçoit en plus un hook et des règles prêtes pour son CLAUDE.md.
Combien ça coûte ?
Rien. SecretBar est open source sous licence MIT.
Quelle version de macOS faut-il ?
macOS 14 ou ultérieur sur un Mac avec Secure Enclave (puce Apple ou T2). Le stockage post-quantique exige macOS 26. La recherche par le sens exige macOS 27 avec Apple Intelligence.
Puis-je transférer mes secrets vers un nouveau Mac ?
Oui. secret export écrit un fichier chiffré avec AES-256 et votre mot de passe de sauvegarde. secret restore le lit sur le nouveau Mac.

Installation

Trois lignes, puis signez ici.

  1. La commande, les deux assistants et la complétion zsh
    $ brew install secretbar/tap/secretbar
  2. Le stockage, puis le premier secret, saisi dans une boîte de dialogue
    $ secret init && secret ask MY_TOKEN
  3. Le hook Claude Code, les règles de l’agent et l’app de barre des menus
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 ou ultérieur. Aucune dépendance hors des outils du système. Gratuit et open source, MIT.
