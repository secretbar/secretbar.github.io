Funciones

    
Hecho para trabajar con un agente.

  

  

    

      
⌘

      
Entrada oculta

      
secret ask NAME abre un diálogo de macOS. Tú escribes el valor. El agente recibe stored: NAME. secret gen crea un valor aleatorio que nadie ve.

      
$ secret gen -l 32 -c "shop: db password" SHOP_DB_PASSWORD
stored: SHOP_DB_PASSWORD

    

    

      
***

      
Salida enmascarada

      
run --mask sustituye cada valor por *** en stdout y stderr, también en base64 y codificación URL. Siempre activo con Claude Code.

    

    

      

      
Hook para Claude Code

      
Detiene secret get, cat .env, security … -w y env dentro de run antes de que se ejecuten.

      
cat .envBloqueado por SecretBar

    

    

      
PQ

      
Almacén poscuántico

      
Desde macOS 26, dos claves de la Secure Enclave sellan cada valor: P-256 y ML-KEM-768. Un archivo copiado hoy sigue cerrado para un ordenador cuántico futuro. secret touchid pq convierte un almacén antiguo tras un solo Touch ID.

    

    

      
⏲

      
Préstamo para un agente

      
secret lease --for 8h NAME… mantiene los secretos indicados hasta 24 horas tras un Touch ID que los nombra. Se pueden leer con la pantalla bloqueada. Cualquier otro nombre falla al instante con not leased. secret lease --revoke lo termina.

    

    

      
?

      
Búsqueda por significado

      
secret ls --ask "shop database password" encuentra nombres con el modelo de Apple en el dispositivo de macOS 27. El modelo solo ve nombres y comentarios, nunca un valor, y nada sale del Mac.

    

    

      
⇪

      
GitHub Actions

      
secret gh NAME -R owner/repo envía un valor a gh secret set por stdin, tras tu confirmación.

    

    

      
🍪

      
Sesiones del navegador

      
secret cookie pull DOMAIN --all --as NAME lleva una sesión de Safari al almacén como cookie jar. Una extensión de Safari captura las cookies de sesión. secret run --cookie-jar NAME da a curl un jar temporal que se borra tras el comando.

    

    

      
.env

      
Referencias, no valores

      
TOKEN=secret:MY_TOKEN en tu .env. secret import traslada un archivo existente. secret check muestra lo que falta.

Seguridad

    
Lo que impide.
Y lo que no.

  

  

    
Un valor en el chat
Entrada por diálogo, generación, salida enmascarada, el hook.
Un valor en una codificación propia, por ejemplo base64(user:pass).

    
Un valor en ps
Los valores pasan por stdin y descriptores de archivo.
set NAME VALUE con el valor como argumento.

    
Un proceso lee a tus espaldas
La clave de la Secure Enclave solo funciona tras Touch ID o el Apple Watch, para cualquier proceso con cualquier firma.
Dentro del periodo de gracia. Es deslizante: 30 minutos sin uso, 8 horas como máximo. Bloquear o dormir el Mac lo termina.

    
Pérdida del Mac
secret export: AES-256, PBKDF2 con 600 000 iteraciones.
Nadie puede recuperar una contraseña de copia olvidada.

  






  

    
FAQ

    
Preguntas.

  

  

    
¿Ve alguna vez el agente de IA el valor de un secreto?
No. El agente trabaja con nombres. El valor va al entorno del comando que lo necesita y la salida vuelve con *** en lugar del valor. Un hook para Claude Code detiene los comandos que mostrarían un valor.

    
¿Dónde se guardan los secretos?
En un único archivo cifrado en tu Mac. Las claves de la Secure Enclave sellan cada valor. Leer exige Touch ID, el Apple Watch o la contraseña del Mac. Nada va a la nube.

    
¿Con qué agentes de IA funciona?
Con cualquier agente que ejecute comandos de shell: Claude Code, Codex, Cursor, Aider y otros. Claude Code además recibe un hook y reglas listas para su CLAUDE.md.

    
¿Cuánto cuesta?
Nada. SecretBar es de código abierto con licencia MIT.

    
¿Qué versión de macOS necesito?
macOS 14 o posterior en un Mac con Secure Enclave (chip de Apple o T2). El almacén poscuántico necesita macOS 26. La búsqueda por significado necesita macOS 27 con Apple Intelligence.

    
¿Puedo pasar mis secretos a un Mac nuevo?
Sí. secret export escribe un archivo cifrado con AES-256 y tu contraseña de copia. secret restore lo lee en el Mac nuevo.
