Un protocolo para secretos y agentes de IA · macOS

Tu agente conoce el nombre.
Nunca el valor.

SecretBar es un comando y una app de la barra de menús para el Mac. Las contraseñas, los tokens y las claves de API se quedan en la Secure Enclave. El agente pide por nombre, una persona confirma, el proceso recibe el valor y la salida vuelve censurada.

El protocolo

El valor sigue seis reglas.

Cada función de SecretBar aplica una de ellas. Ninguna depende de que el agente se porte bien.

  1. §1

    Entrada

    Una persona escribe el valor en un diálogo oculto de macOS: secret ask NAME. El chat nunca lo ve. secret gen crea un valor aleatorio que nadie ve.

  2. §2

    Almacenamiento

    Claves de la Secure Enclave sellan cada valor: P-256 y ML-KEM-768, poscuántico. Todo el archivo se cifra otra vez. Nada va a la nube.

  3. §3

    Acceso

    Cada lectura requiere Touch ID o el Apple Watch. El periodo de gracia se desliza durante 30 minutos y termina al bloquearse la pantalla. Una concesión da a un agente secretos con nombre durante 24 horas como máximo, tras un solo Touch ID.

  4. §4

    Uso

    secret run pone el valor en el entorno de un solo proceso. No en argv, ni en un archivo, ni en el chat. Un archivo .env guarda referencias: secret:NAME.

  5. §5

    Salida

    Cada valor en stdout y stderr vuelve como ***, también en base64 y en codificación URL. Un hook para Claude Code detiene cat .env, secret get y env antes de que se ejecuten.

  6. §6

    Registro

    Un registro de accesos guarda quién leyó qué nombre y cuándo: agent o human. Solo nombres.

También incluye

  • Búsqueda por significado. secret ls --ask "shop database" encuentra nombres con el modelo local de macOS 27. Lee nombres y comentarios, nunca valores.
  • Sesiones del navegador. Una sesión de Safari pasa al almacén como cookie jar. curl la usa, el agente nunca ve una cookie.
  • GitHub Actions. secret gh NAME -R owner/repo envía un valor a gh secret set por stdin, después de que confirmes.
  • Caducidad y copia. Los tokens con fecha te avisan antes de caducar. secret export escribe un solo archivo AES-256 para un Mac nuevo.
  • Cualquier agente. Claude Code, Codex, Cursor, Aider: cualquier agente que ejecute comandos de shell. Claude Code recibe además el hook y reglas listas.

La app de la barra de menús

La parte humana del protocolo.

⌥⌘S desde cualquier app, Spotlight, Siri y Atajos. Una ficha por secreto con los archivos .env que lo usan. La app nunca lee un valor: el asistente lo copia al portapapeles y lo borra a los 30 segundos.

  • Búsqueda rápida: ↩ copia la referencia, ⇧↩ el valor
  • + en la barra de menús: un secreto nuevo, con su referencia en el portapapeles
  • Actividad: ejecuciones del agente y solicitudes de Touch ID

Preguntas

¿Ve alguna vez el agente de IA el valor de un secreto?
No. El agente trabaja con nombres. El valor va al entorno del comando que lo necesita y la salida vuelve con *** en lugar del valor. Un hook para Claude Code detiene los comandos que mostrarían un valor.
¿Dónde se guardan los secretos?
En un solo archivo cifrado en tu Mac. Claves de la Secure Enclave sellan cada valor. Una lectura requiere Touch ID, el Apple Watch o la contraseña del Mac. Nada va a la nube.
¿Con qué agentes de IA funciona?
Con cualquier agente que ejecute comandos de shell: Claude Code, Codex, Cursor, Aider y otros. Claude Code recibe además un hook y reglas listas para su CLAUDE.md.
¿Cuánto cuesta?
Nada. SecretBar es de código abierto, con licencia MIT.
¿Qué versión de macOS necesito?
macOS 14 o posterior en un Mac con Secure Enclave (chip de Apple o T2). El almacén poscuántico necesita macOS 26. La búsqueda por significado necesita macOS 27 con Apple Intelligence.
¿Puedo pasar mis secretos a un Mac nuevo?
Sí. secret export escribe un archivo cifrado con AES-256 y tu contraseña de copia. secret restore lo lee en el Mac nuevo.

Instalación

Tres líneas. Luego, firma aquí.

  1. El comando, los dos asistentes y el autocompletado de zsh
    $ brew install secretbar/tap/secretbar
  2. El almacén y luego el primer secreto, escrito en un diálogo
    $ secret init && secret ask MY_TOKEN
  3. El hook para Claude Code, las reglas del agente y la app de la barra de menús
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 o posterior. Sin dependencias más allá de las herramientas del sistema. Gratis y de código abierto, MIT.
