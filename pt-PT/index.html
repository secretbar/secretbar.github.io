Funcionalidades

    
Feito para trabalhar com um agente.

  

  

    

      
⌘

      
Introdução oculta

      
secret ask NAME abre um diálogo do macOS. Escreve o valor. O agente recebe stored: NAME. secret gen cria um valor aleatório que ninguém vê.

      
$ secret gen -l 32 -c "shop: db password" SHOP_DB_PASSWORD
stored: SHOP_DB_PASSWORD

    

    

      
***

      
Saída mascarada

      
run --mask substitui cada valor por *** em stdout e stderr, também em base64 e codificação URL. Sempre ativo no Claude Code.

    

    

      

      
Hook para Claude Code

      
Bloqueia secret get, cat .env, security … -w e env dentro de run antes de arrancarem.

      
cat .envBloqueado pelo SecretBar

    

    

      
PQ

      
Armazenamento pós-quântico

      
A partir do macOS 26, duas chaves da Secure Enclave selam cada valor: P-256 e ML-KEM-768. Um ficheiro copiado hoje continua fechado para um futuro computador quântico. secret touchid pq converte um armazenamento antigo após um único Touch ID.

    

    

      
⏲

      
Concessão a um agente

      
secret lease --for 8h NAME… mantém os segredos indicados até 24 horas após um Touch ID que os nomeia. Continuam legíveis com o ecrã bloqueado. Qualquer outro nome falha de imediato com not leased. secret lease --revoke termina-a.

    

    

      
?

      
Pesquisa por significado

      
secret ls --ask "shop database password" encontra nomes com o modelo da Apple no dispositivo do macOS 27. O modelo só vê nomes e comentários, nunca um valor, e nada sai do Mac.

    

    

      
⇪

      
GitHub Actions

      
secret gh NAME -R owner/repo envia um valor para gh secret set via stdin, depois de o confirmar.

    

    

      
🍪

      
Sessões do navegador

      
secret cookie pull DOMAIN --all --as NAME passa uma sessão do Safari para o armazenamento como cookie jar. Uma extensão do Safari captura os cookies de sessão. secret run --cookie-jar NAME dá ao curl um jar temporário apagado após o comando.

    

    

      
.env

      
Referências, não valores

      
TOKEN=secret:MY_TOKEN no seu .env. secret import migra um ficheiro existente. secret check mostra o que falta.

Validade e cópia de segurança

Funciona com qualquer agente

      
Claude Code, Codex, Cursor, Aider: qualquer agente que execute comandos de shell usa secret run. O Claude Code recebe ainda o hook e regras prontas para CLAUDE.md.

$ secret run --mask -e .env -- npm test

Segurança

    
O que impede.
E o que não impede.

  

  

    
Um valor no chat
Introdução no diálogo, geração, saída mascarada, o hook.
Um valor numa codificação própria, por exemplo base64(user:pass).

    
Um valor em ps
Os valores passam por stdin e descritores de ficheiro.
set NAME VALUE com o valor como argumento.

    
Um processo lê nas suas costas
A chave da Secure Enclave só funciona após Touch ID ou Apple Watch, para qualquer processo com qualquer assinatura.
Dentro do período de tolerância. É deslizante: 30 minutos inativo, 8 horas no máximo. O bloqueio do ecrã ou a pausa terminam-no.

    
Perda do Mac
secret export: AES-256, PBKDF2 com 600 000 iterações.
Ninguém consegue recuperar uma palavra-passe de cópia esquecida.

  






  

    
FAQ

    
Perguntas.

  

  

    
O agente de IA alguma vez vê o valor de um segredo?
Não. O agente trabalha com nomes. O valor vai para o ambiente do comando que precisa dele e a saída volta com *** em vez do valor. Um hook para Claude Code bloqueia os comandos que mostrariam um valor.

    
Onde ficam guardados os segredos?
Num único ficheiro cifrado no seu Mac. Chaves na Secure Enclave selam cada valor. Ler exige Touch ID, Apple Watch ou a palavra-passe do Mac. Nada vai para a nuvem.

    
Com que agentes de IA funciona?
Com qualquer agente que execute comandos de shell: Claude Code, Codex, Cursor, Aider e outros. O Claude Code recebe ainda um hook e regras prontas para o seu CLAUDE.md.

    
Quanto custa?
Nada. O SecretBar é open source com licença MIT.

    
Que versão do macOS é necessária?
macOS 14 ou posterior num Mac com Secure Enclave (chip Apple ou T2). O armazenamento pós-quântico requer macOS 26. A pesquisa por significado requer macOS 27 com Apple Intelligence.

    
Posso passar os meus segredos para um novo Mac?
Sim. secret export escreve um ficheiro cifrado com AES-256 e a sua palavra-passe de cópia. secret restore lê-o no novo Mac.
