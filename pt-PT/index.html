Um protocolo para segredos e agentes de IA · macOS

O seu agente conhece o nome.
Nunca o valor.

O SecretBar é um comando e uma app da barra de menus para o Mac. Palavras-passe, tokens e chaves de API ficam na Secure Enclave. O agente pede pelo nome, uma pessoa confirma, o processo recebe o valor e a saída volta rasurada.

$ brew install secretbar/tap/secretbar

O protocolo

O valor segue seis regras.

Cada funcionalidade do SecretBar impõe uma delas. Nenhuma depende do bom comportamento do agente.

  1. §1

    Introdução

    Uma pessoa escreve o valor numa caixa de diálogo oculta do macOS: secret ask NAME. O chat nunca o vê. secret gen cria um valor aleatório que ninguém vê.

  2. §2

    Armazenamento

    Chaves na Secure Enclave selam cada valor: P-256 e ML-KEM-768, pós-quântico. O ficheiro inteiro é cifrado de novo. Nada vai para a nuvem.

  3. §3

    Acesso

    Cada leitura requer Touch ID ou Apple Watch. O período de tolerância desliza durante 30 minutos e termina quando o ecrã bloqueia. Uma concessão dá a um agente segredos indicados pelo nome até 24 horas, após um único Touch ID.

  4. §4

    Utilização

    secret run coloca o valor no ambiente de um único processo. Não em argv, num ficheiro ou no chat. Um ficheiro .env guarda referências: secret:NAME.

  5. §5

    Saída

    Cada valor em stdout e stderr volta como ***, também em base64 e em codificação URL. Um hook para Claude Code bloqueia cat .env, secret get e env antes de correrem.

  6. §6

    Registo

    Um registo de acessos guarda quem leu que nome e quando: agent ou human. Só nomes.

Também incluído

  • Pesquisa por significado. secret ls --ask "shop database" encontra nomes com o modelo local do macOS 27. Lê nomes e comentários, nunca valores.
  • Sessões do browser. Uma sessão do Safari passa para o armazenamento como cookie jar. O curl usa-a, o agente nunca vê um cookie.
  • GitHub Actions. secret gh NAME -R owner/repo envia um valor para gh secret set pelo stdin, depois de confirmar.
  • Validade e cópia. Os tokens com data avisam antes de expirar. secret export escreve um único ficheiro AES-256 para um Mac novo.
  • Qualquer agente. Claude Code, Codex, Cursor, Aider: qualquer agente que execute comandos de shell. O Claude Code recebe ainda o hook e regras prontas.

A app da barra de menus

O lado humano do protocolo.

⌥⌘S a partir de qualquer app, Spotlight, Siri e Atalhos. Um cartão por segredo com os ficheiros .env que o usam. A app nunca lê um valor: o auxiliar coloca-o na área de transferência e limpa-o ao fim de 30 segundos.

  • Pesquisa rápida: ↩ copia a referência, ⇧↩ o valor
  • + na barra de menus: um segredo novo, com a referência na área de transferência
  • Atividade: execuções do agente e pedidos de Touch ID

Perguntas

O agente de IA alguma vez vê o valor de um segredo?
Não. O agente trabalha com nomes. O valor vai para o ambiente do comando que precisa dele e a saída volta com *** em vez do valor. Um hook para Claude Code bloqueia os comandos que mostrariam um valor.
Onde ficam guardados os segredos?
Num único ficheiro cifrado no seu Mac. Chaves na Secure Enclave selam cada valor. Uma leitura requer Touch ID, Apple Watch ou a palavra-passe do Mac. Nada vai para a nuvem.
Com que agentes de IA funciona?
Com qualquer agente que execute comandos de shell: Claude Code, Codex, Cursor, Aider e outros. O Claude Code recebe ainda um hook e regras prontas para o seu CLAUDE.md.
Quanto custa?
Nada. O SecretBar é open source, com licença MIT.
Que versão do macOS é necessária?
macOS 14 ou posterior num Mac com Secure Enclave (chip Apple ou T2). O armazenamento pós-quântico requer macOS 26. A pesquisa por significado requer macOS 27 com Apple Intelligence.
Posso passar os meus segredos para um Mac novo?
Sim. secret export escreve um ficheiro cifrado com AES-256 e a sua palavra-passe de cópia. secret restore lê-o no novo Mac.

Instalação

Três linhas, depois assine aqui.

  1. O comando, os dois auxiliares e o preenchimento automático do zsh
    $ brew install secretbar/tap/secretbar
  2. O armazenamento e depois o primeiro segredo, escrito numa caixa de diálogo
    $ secret init && secret ask MY_TOKEN
  3. O hook para Claude Code, as regras do agente e a app da barra de menus
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 ou posterior. Sem dependências além das ferramentas do sistema. Gratuito e open source, MIT.
