Funkcje

    
Stworzony do pracy z agentem.

  

  

    

      
⌘

      
Ukryte wpisywanie

      
secret ask NAME otwiera okno macOS. Ty wpisujesz wartość. Agent dostaje stored: NAME. secret gen tworzy losową wartość, której nikt nie widzi.

      
$ secret gen -l 32 -c "shop: db password" SHOP_DB_PASSWORD
stored: SHOP_DB_PASSWORD

    

    

      
***

      
Maskowane wyjście

      
run --mask zastępuje każdą wartość przez *** w stdout i stderr, także w base64 i kodowaniu URL. Pod Claude Code zawsze włączone.

    

    

      

      
Hook dla Claude Code

      
Zatrzymuje secret get, cat .env, security … -w i env wewnątrz run, zanim się uruchomią.

      
cat .envZablokowane przez SecretBar

    

    

      
PQ

      
Magazyn postkwantowy

      
Od macOS 26 dwa klucze Secure Enclave pieczętują każdą wartość: P-256 i ML-KEM-768. Plik skopiowany dziś pozostanie zamknięty dla przyszłego komputera kwantowego. secret touchid pq konwertuje stary magazyn po jednym Touch ID.

    

    

      
⏲

      
Dzierżawa dla agenta

      
secret lease --for 8h NAME… udostępnia wskazane sekrety do 24 godzin po jednym Touch ID, które je wymienia. Są czytelne także przy zablokowanym ekranie. Każda inna nazwa od razu kończy się not leased. secret lease --revoke ją kończy.

    

    

      
?

      
Wyszukiwanie po znaczeniu

      
secret ls --ask "shop database password" znajduje nazwy lokalnym modelem Apple w macOS 27. Model widzi tylko nazwy i komentarze, nigdy wartość, i nic nie opuszcza Maca.

    

    

      
⇪

      
GitHub Actions

      
secret gh NAME -R owner/repo przekazuje wartość do gh secret set przez stdin, po Twoim potwierdzeniu.

    

    

      
🍪

      
Sesje przeglądarki

      
secret cookie pull DOMAIN --all --as NAME przenosi sesję Safari do magazynu jako cookie jar. Rozszerzenie Safari przechwytuje ciasteczka sesyjne. secret run --cookie-jar NAME daje curl tymczasowy jar, usuwany po poleceniu.

    

    

      
.env

      
Odwołania, nie wartości

      
TOKEN=secret:MY_TOKEN w Twoim .env. secret import przenosi istniejący plik. secret check pokazuje, czego brakuje.

Działa z każdym agentem

      
Claude Code, Codex, Cursor, Aider: każdy agent, który uruchamia polecenia powłoki, używa secret run. Claude Code dostaje też hook i gotowe reguły dla CLAUDE.md.

$ secret run --mask -e .env -- npm test

FAQ

    
Pytania.

  

  

    
Czy agent AI kiedykolwiek widzi wartość sekretu?
Nie. Agent pracuje na nazwach. Wartość trafia do środowiska polecenia, które jej potrzebuje, a wyjście wraca z *** zamiast wartości. Hook dla Claude Code zatrzymuje polecenia, które wypisałyby wartość.

    
Gdzie są przechowywane sekrety?
W jednym zaszyfrowanym pliku na Twoim Macu. Klucze w Secure Enclave pieczętują każdą wartość. Odczyt wymaga Touch ID, Apple Watch lub hasła Maca. Nic nie trafia do chmury.

    
Z jakimi agentami AI działa?
Z każdym agentem, który uruchamia polecenia powłoki: Claude Code, Codex, Cursor, Aider i innymi. Claude Code dostaje też hook i gotowe reguły do swojego CLAUDE.md.

    
Ile to kosztuje?
Nic. SecretBar jest open source na licencji MIT.

    
Jakiej wersji macOS potrzebuję?
macOS 14 lub nowszego na Macu z Secure Enclave (układ Apple lub T2). Magazyn postkwantowy wymaga macOS 26. Wyszukiwanie po znaczeniu wymaga macOS 27 z Apple Intelligence.

    
Czy mogę przenieść sekrety na nowego Maca?
Tak. secret export zapisuje jeden plik zaszyfrowany AES-256 i Twoim hasłem kopii zapasowej. secret restore odczytuje go na nowym Macu.
