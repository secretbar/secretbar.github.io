Protokół dla sekretów i agentów AI · macOS

Twój agent zna nazwę.
Nigdy wartości.

SecretBar to polecenie i aplikacja na pasek menu dla Maca. Hasła, tokeny i klucze API zostają w Secure Enclave. Agent prosi po nazwie, człowiek potwierdza, proces dostaje wartość, a wyjście wraca zaczernione.

$ brew install secretbar/tap/secretbar

Protokół

Sześć zasad, których trzyma się wartość.

Każda funkcja SecretBar egzekwuje jedną z nich. Żadna nie zależy od dobrego zachowania agenta.

  1. §1

    Wprowadzanie

    Człowiek wpisuje wartość w ukrytym oknie macOS: secret ask NAME. Czat nigdy jej nie widzi. secret gen tworzy losową wartość, której nikt nie widzi.

  2. §2

    Przechowywanie

    Klucze w Secure Enclave pieczętują każdą wartość: P-256 i postkwantowy ML-KEM-768. Cały plik jest szyfrowany jeszcze raz. Nic nie trafia do chmury.

  3. §3

    Dostęp

    Każdy odczyt wymaga Touch ID lub Apple Watch. Okres karencji przesuwa się o 30 minut i kończy się po zablokowaniu ekranu. Dzierżawa daje agentowi wskazane sekrety do 24 godzin, po jednym Touch ID.

  4. §4

    Użycie

    secret run wstawia wartość do środowiska jednego procesu. Nie do argv, pliku ani czatu. Plik .env zawiera odwołania: secret:NAME.

  5. §5

    Wyjście

    Każda wartość w stdout i stderr wraca jako ***, także w base64 i w kodowaniu URL. Hook dla Claude Code zatrzymuje cat .env, secret get i env, zanim się uruchomią.

  6. §6

    Ślad

    Dziennik dostępu zapisuje, kto i kiedy odczytał którą nazwę: agent lub human. Tylko nazwy.

Także w zestawie

  • Wyszukiwanie po znaczeniu. secret ls --ask "shop database" znajduje nazwy lokalnym modelem macOS 27. Czyta nazwy i komentarze, nigdy wartości.
  • Sesje przeglądarki. Sesja Safari trafia do magazynu jako cookie jar. curl z niej korzysta, agent nigdy nie widzi ciasteczka.
  • GitHub Actions. secret gh NAME -R owner/repo przekazuje wartość do gh secret set przez stdin, po Twoim potwierdzeniu.
  • Terminy i kopia. Tokeny z datą przypominają o sobie przed wygaśnięciem. secret export zapisuje jeden plik AES-256 dla nowego Maca.
  • Dowolny agent. Claude Code, Codex, Cursor, Aider: każdy agent, który uruchamia polecenia powłoki. Claude Code dostaje dodatkowo hook i gotowe reguły.

Aplikacja na pasek menu

Ludzka strona protokołu.

⌥⌘S z każdej aplikacji, Spotlight, Siri i Skróty. Karta dla każdego sekretu z plikami .env, które go używają. Aplikacja nigdy nie czyta wartości: pomocnik kładzie ją w schowku i czyści go po 30 sekundach.

  • Szybkie wyszukiwanie: ↩ kopiuje odwołanie, ⇧↩ wartość

Pytania

Czy agent AI kiedykolwiek widzi wartość sekretu?
Nie. Agent pracuje na nazwach. Wartość trafia do środowiska polecenia, które jej potrzebuje, a wyjście wraca z *** zamiast wartości. Hook dla Claude Code zatrzymuje polecenia, które wypisałyby wartość.
Gdzie są przechowywane sekrety?
W jednym zaszyfrowanym pliku na Twoim Macu. Klucze w Secure Enclave pieczętują każdą wartość. Odczyt wymaga Touch ID, Apple Watch lub hasła Maca. Nic nie trafia do chmury.
Z jakimi agentami AI działa?
Z każdym agentem, który uruchamia polecenia powłoki: Claude Code, Codex, Cursor, Aider i innymi. Claude Code dostaje dodatkowo hook i gotowe reguły do swojego CLAUDE.md.
Ile to kosztuje?
Nic. SecretBar jest open source na licencji MIT.
Jakiej wersji macOS potrzebuję?
macOS 14 lub nowszego na Macu z Secure Enclave (układ Apple lub T2). Magazyn postkwantowy wymaga macOS 26. Wyszukiwanie po znaczeniu wymaga macOS 27 z Apple Intelligence.
Czy mogę przenieść sekrety na nowego Maca?
Tak. secret export zapisuje jeden plik zaszyfrowany AES-256 i Twoim hasłem kopii zapasowej. secret restore odczytuje go na nowym Macu.

Instalacja

Trzy linijki. Potem podpis tutaj.

  1. Polecenie, oba pomocniki i uzupełnianie dla zsh
    $ brew install secretbar/tap/secretbar
  2. Magazyn, potem pierwszy sekret, wpisany w oknie
    $ secret init && secret ask MY_TOKEN
  3. Hook dla Claude Code, reguły dla agenta i aplikacja na pasek menu
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 lub nowszy. Bez zależności poza narzędziami systemu. Darmowe i open source, MIT.
