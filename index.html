A protocol for secrets and AI agents · macOS

Your agent knows the name.
Never the value.

SecretBar is a command and a menu bar app for the Mac. Passwords, tokens and API keys stay in the Secure Enclave. The agent asks by name, a human confirms, the process gets the value, and the output comes back redacted.

$ brew install secretbar/tap/secretbar

The protocol

Six rules the value follows.

Every feature of SecretBar enforces one of them. None of them depends on the agent behaving well.

  1. §1

    Input

    A human types the value into a hidden macOS dialog: secret ask NAME. The chat never sees it. secret gen makes a random value that nobody sees.

  2. §2

    Storage

    Keys in the Secure Enclave seal each value: P-256 and post-quantum ML-KEM-768. The whole file is encrypted again. Nothing goes to a cloud.

  3. §3

    Access

    A read needs Touch ID or Apple Watch. The grace time slides for 30 minutes and ends when the screen locks. A lease gives an agent named secrets for up to 24 hours, after one Touch ID.

  4. §4

    Use

    secret run puts the value into the environment of one process. Not into argv, a file or the chat. A .env file holds references: secret:NAME.

  5. §5

    Output

    Each value in stdout and stderr comes back as ***, also in base64 and URL encoding. A Claude Code hook stops cat .env, secret get and env before they run.

  6. §6

    Record

    An access log keeps who read which name and when: agent or human. Names only.

Also in the box

  • Search by meaning. secret ls --ask "shop database" finds names with the on-device model of macOS 27. It reads names and comments, never values.
  • Browser sessions. A Safari session moves into the store as a cookie jar. curl uses it, the agent never sees a cookie.
  • GitHub Actions. secret gh NAME -R owner/repo sends a value to gh secret set on stdin, after you confirm.
  • Expiry and backup. Tokens with a date remind you before they expire. secret export writes one AES-256 file for a new Mac.
  • YOLO mode. Off by default. secret yolo on or the switch in the menu asks Touch ID once. Then agents read every secret with no question until you turn it off, also with a locked screen. The output stays masked, and only you can turn it on.
  • Any agent. Claude Code, Codex, Cursor, Aider: any agent that runs shell commands. Claude Code also gets the hook and ready rules.

The menu bar app

The human side of the protocol.

⌥⌘S from any app, Spotlight, Siri and Shortcuts. A card for each secret with the .env files that use it. The app never reads a value: the helper puts it on the clipboard and clears it after 30 seconds.

  • Quick search: ↩ copies the reference, ⇧↩ the value
  • + in the menu bar: a new secret, its reference on the clipboard
  • Activity: agent runs and Touch ID prompts

Questions

Does the AI agent ever see the value of a secret?
No. The agent works with names. The value goes into the environment of the command that needs it, and the output comes back with *** in place of the value. A Claude Code hook stops commands that would print a value.
Where are the secrets stored?
In one encrypted file on your Mac. Keys in the Secure Enclave seal each value. A read needs Touch ID, Apple Watch or the Mac password. Nothing goes to a cloud.
Which AI agents does it work with?
Any agent that runs shell commands: Claude Code, Codex, Cursor, Aider and others. Claude Code also gets a hook and ready rules for its CLAUDE.md.
What does it cost?
Nothing. SecretBar is open source under the MIT license.
Which macOS version do I need?
macOS 14 or later on a Mac with a Secure Enclave (Apple silicon or T2). The post-quantum store needs macOS 26. Search by meaning needs macOS 27 with Apple Intelligence.
Can I move my secrets to a new Mac?
Yes. secret export writes one file encrypted with AES-256 and your backup password. secret restore reads it on the new Mac.

Install

Three lines, then sign here.

  1. The command, both helpers and zsh completion
    $ brew install secretbar/tap/secretbar
  2. The store, then the first secret, typed in a dialog
    $ secret init && secret ask MY_TOKEN
  3. The Claude Code hook, the agent rules and the menu bar app
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 or later. No dependencies beyond the system tools. Free and open source, MIT.
