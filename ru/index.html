Возможности

    
Сделан для работы с агентом.

  

  

    

      
⌘

      
Скрытый ввод

      
secret ask NAME открывает окно macOS. Вы вводите значение. Агент получает stored: NAME. secret gen создаёт случайное значение, которое никто не видит.

      
$ secret gen -l 32 -c "shop: db password" SHOP_DB_PASSWORD
stored: SHOP_DB_PASSWORD

    

    

      
***

      
Маскированный вывод

      
run --mask заменяет каждое значение на *** в stdout и stderr, также в base64 и URL-кодировке. Под Claude Code включено всегда.

    

    

      

      
Хук для Claude Code

      
Останавливает secret get, cat .env, security … -w и env внутри run до их запуска.

      
cat .envЗаблокировано SecretBar

    

    

      
PQ

      
Постквантовое хранилище

      
С macOS 26 два ключа Secure Enclave запечатывают каждое значение: P-256 и ML-KEM-768. Файл, скопированный сегодня, останется закрытым и для будущего квантового компьютера. secret touchid pq переводит старое хранилище после одного Touch ID.

    

    

      
⏲

      
Аренда для агента

      
secret lease --for 8h NAME… держит названные секреты до 24 часов после одного Touch ID, в котором они перечислены. Они читаются и при заблокированном экране. Любое другое имя сразу получает not leased. secret lease --revoke завершает аренду.

    

    

      
?

      
Поиск по смыслу

      
secret ls --ask "shop database password" находит имена с помощью встроенной модели Apple в macOS 27. Модель видит только имена и комментарии, никогда значения, и ничто не покидает Mac.

    

    

      
⇪

      
GitHub Actions

      
secret gh NAME -R owner/repo передаёт значение в gh secret set через stdin, после вашего подтверждения.

    

    

      
🍪

      
Сессии браузера

      
secret cookie pull DOMAIN --all --as NAME переносит сессию Safari в хранилище как cookie jar. Расширение Safari захватывает сессионные cookie. secret run --cookie-jar NAME даёт curl временный jar, который удаляется после команды.

    

    

      
.env

      
Ссылки, а не значения

      
TOKEN=secret:MY_TOKEN в вашем .env. secret import переносит готовый файл. secret check показывает, чего не хватает.

Безопасность

    
Что он защищает.
И что нет.

  

  

    
Значение в чате
Ввод в окне, генерация, маскированный вывод, хук.
Значение в своей кодировке, например base64(user:pass).

    
Значение в ps
Значения идут через stdin и файловые дескрипторы.
set NAME VALUE со значением в аргументе.

    
Процесс читает у вас за спиной
Ключ Secure Enclave работает только после Touch ID или Apple Watch, для любого процесса с любой подписью.
Внутри льготного окна. Оно скользит: 30 минут простоя, не более 8 часов. Блокировка экрана или сон его завершают.

    
Потеря Mac
secret export: AES-256, PBKDF2, 600 000 итераций.
Забытый пароль резервной копии не восстановит никто.

  






  

    
Вопросы

    
Вопросы.

  

  

    
Видит ли ИИ-агент когда-нибудь значение секрета?
Нет. Агент работает с именами. Значение идёт в окружение команды, которой оно нужно, а вывод возвращается с *** на месте значения. Хук для Claude Code останавливает команды, которые напечатали бы значение.

    
Где хранятся секреты?
В одном зашифрованном файле на вашем Mac. Ключи в Secure Enclave запечатывают каждое значение. Для чтения нужен Touch ID, Apple Watch или пароль Mac. Ничего не уходит в облако.

    
С какими ИИ-агентами он работает?
С любым агентом, который запускает команды оболочки: Claude Code, Codex, Cursor, Aider и другими. Claude Code также получает хук и готовые правила для своего CLAUDE.md.

    
Сколько это стоит?
Нисколько. SecretBar — открытый код под лицензией MIT.

    
Какая версия macOS нужна?
macOS 14 или новее на Mac с Secure Enclave (чип Apple или T2). Постквантовому хранилищу нужна macOS 26. Поиску по смыслу нужна macOS 27 с Apple Intelligence.

    
Можно ли перенести секреты на новый Mac?
Да. secret export пишет один файл, зашифрованный AES-256 и вашим паролем резервной копии. secret restore читает его на новом Mac.
