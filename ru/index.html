Протокол для секретов и ИИ-агентов · macOS

Ваш агент знает имя.
Но не значение.

SecretBar — команда и приложение в строке меню для Mac. Пароли, токены и API-ключи остаются в Secure Enclave. Агент просит по имени, человек подтверждает, процесс получает значение, а вывод возвращается с вымаранными значениями.

$ brew install secretbar/tap/secretbar

Протокол

Шесть правил, по которым живёт значение.

Каждая функция SecretBar обеспечивает одно из них. Ни одно не зависит от того, хорошо ли ведёт себя агент.

  1. §1

    Ввод

    Человек вводит значение в скрытое окно macOS: secret ask NAME. Чат его не видит. secret gen создаёт случайное значение, которого не видит никто.

  2. §2

    Хранение

    Ключи в Secure Enclave запечатывают каждое значение: P-256 и постквантовый ML-KEM-768. Весь файл зашифрован ещё раз. В облако не уходит ничего.

  3. §3

    Доступ

    Каждое чтение требует Touch ID или Apple Watch. Льготное окно скользит 30 минут и закрывается при блокировке экрана. Аренда даёт агенту названные секреты до 24 часов после одного Touch ID.

  4. §4

    Использование

    secret run кладёт значение в окружение одного процесса. Не в argv, не в файл и не в чат. Файл .env хранит ссылки: secret:NAME.

  5. §5

    Вывод

    Каждое значение в stdout и stderr возвращается как ***, также в base64 и URL-кодировке. Хук для Claude Code останавливает cat .env, secret get и env до запуска.

  6. §6

    Учёт

    Журнал доступа хранит, кто, какое имя и когда прочитал: agent или human. Только имена.

Что ещё в комплекте

  • Поиск по смыслу. secret ls --ask "shop database" находит имена встроенной моделью macOS 27. Она читает имена и комментарии, никогда значения.
  • Сессии браузера. Сессия Safari переходит в хранилище как cookie jar. Ей пользуется curl, агент не видит ни одного cookie.
  • GitHub Actions. secret gh NAME -R owner/repo передаёт значение в gh secret set через stdin, после вашего подтверждения.
  • Сроки и резервная копия. О токенах со сроком действия SecretBar напомнит заранее. secret export пишет один файл AES-256 для нового Mac.
  • Режим YOLO. По умолчанию выключен. secret yolo on или тумблер в меню один раз спрашивает Touch ID. Дальше агенты читают любой секрет без вопросов, пока вы его не выключите, в том числе при заблокированном экране. Вывод остаётся замаскированным, а включить режим можете только вы.
  • Любой агент. Claude Code, Codex, Cursor, Aider: любой агент, который запускает команды shell. Claude Code получает ещё хук и готовые правила.

Приложение в строке меню

Человеческая сторона протокола.

⌥⌘S из любого приложения, Spotlight, Siri и Команды. Карточка для каждого секрета с файлами .env, которые его используют. Приложение никогда не читает значение: помощник кладёт его в буфер обмена и очищает буфер через 30 секунд.

  • Быстрый поиск: ↩ копирует ссылку, ⇧↩ значение
  • + в строке меню: новый секрет, его ссылка уже в буфере обмена
  • Активность: запуски агента и запросы Touch ID

Вопросы

Видит ли ИИ-агент значение секрета?
Нет. Агент работает с именами. Значение попадает в окружение команды, которой оно нужно, а вывод возвращается с *** вместо значения. Хук для Claude Code останавливает команды, которые вывели бы значение.
Где хранятся секреты?
В одном зашифрованном файле на вашем Mac. Ключи в Secure Enclave запечатывают каждое значение. Для чтения нужен Touch ID, Apple Watch или пароль Mac. В облако не уходит ничего.
С какими ИИ-агентами он работает?
С любым агентом, который запускает команды shell: Claude Code, Codex, Cursor, Aider и другими. Claude Code получает ещё хук и готовые правила для CLAUDE.md.
Сколько это стоит?
Нисколько. SecretBar — открытый код под лицензией MIT.
Какая версия macOS нужна?
macOS 14 или новее на Mac с Secure Enclave (Apple silicon или T2). Постквантовому хранилищу нужна macOS 26. Поиску по смыслу нужна macOS 27 с Apple Intelligence.
Можно ли перенести секреты на новый Mac?
Да. secret export пишет один файл, зашифрованный AES-256 и вашим паролем резервной копии. secret restore читает его на новом Mac.

Установка

Три строки — и подпись.

  1. Команда, оба помощника и автодополнение для zsh
    $ brew install secretbar/tap/secretbar
  2. Хранилище, затем первый секрет, введённый в окне
    $ secret init && secret ask MY_TOKEN
  3. Хук для Claude Code, правила для агента и приложение в строке меню
    $ "$(brew --prefix secretbar)/libexec/install.sh" --claude-hook --app
Touch ID

macOS 14 или новее. Никаких зависимостей, кроме системных инструментов. Бесплатно и с открытым кодом, MIT.
